# Tianyu Xiong · 熊天宇

Bilingual academic website, publications and curriculum vitae.

- [English website](https://six-bit-tx.github.io/research/)
- [中文主页](https://six-bit-tx.github.io/research/zh.html)
- [English CV](https://six-bit-tx.github.io/research/assets/Tianyu_Xiong_CV.pdf)
- [中文简历](https://six-bit-tx.github.io/research/assets/Tianyu_Xiong_CV_zh.pdf)

This is a buildless static site. GitHub Pages serves the root of the `main` branch; `.nojekyll` disables Jekyll processing. Publication metadata is maintained in `publications.js`, with citations in `assets/publications.bib`. Both language pages share the same styles and scripts. The QGVI manuscript is labeled as submitted to arXiv.

Visual inspiration: [RhineLabUI](https://github.com/LBEILC/RhineLabUI).
